# DW-OCR 校正用XDWの一括・分割作成と比較

DW-OCR v0.7.0 Pre-releaseに同梱する2つの作成方式です。
Integrations `0.13.0`、Core `1.0.1`です。
校正結果取込後は `全文Excel出力.bat` も使えます。操作は `docs/user/reviewed-excel.md` を参照してください。

## 実行方法

1. 同じ元のXDWを `ocr開始（一括）.bat` へドロップします。
2. 終了後、同じXDWを `ocr開始（分割）.bat` へドロップします。
3. 各画面に表示される「保存先・計測結果」を確認します。
4. `比較結果作成.bat` を起動し、A、Bの実行フォルダーを順番に入力します。

引数なしでA/Bを起動すると共通の `INPUT` フォルダーを処理します。
`A_一括作成.bat` と `B_ページ別作成と結合.bat` も同じ処理の別名として使えます。
「分割」は校正用XDWをページごとに作成して結合する方式です。
設定は共通の `settings.ini` です。各実行は元のXDWから新しくOCRします。
OCR済み結果の再利用や、ページ単位の途中再開はありません。

| 方式 | 校正用XDWの作成順序 |
|---|---|
| A | 白紙ページを先に結合 → 全ページへ文字配置 → 保存 |
| B | 1ページ作成・文字配置・保存・クローズを繰り返す → 全ページ結合 → 保存 |

両方式とも完成文書を再読み込みして検査し、同じ形式の校正フォルダーを作ります。
`review.xdw` をViewerで校正・保存して閉じ、共通の `校正結果取込.bat` へドロップできます。

## 保存場所

- 完成文書・計測結果：`OUTPUT/A/job-…`、`OUTPUT/B/job-…`
- OCR結果：`runs/A/job-…`、`runs/B/job-…`
- 実行ログ：`logs/job-….log`
- 比較表：`OUTPUT/comparison-…/comparison.txt`・CSV・JSON

実行フォルダー直下に `performance.json` とExcelで開けるUTF-8 BOM付き `performance.csv` を保存します。
校正用XDWはその下の `doc-…/review-session/review.xdw` です。
ファイル名が同じでも毎回別の実行フォルダーを作ります。

## 計測の読み方

全体・OCR・校正用XDW作成・矩形付加・テキストマップ等を分けて計測します。
校正用XDWについては白紙作成、ページ別文字配置、保存、結合、完成後検査も記録します。
`review` は校正フォルダー全体の作成、`review.create` はXDW本体の作成です。
親工程には子工程の時間が含まれるため、全行を合計しないでください。
初期検査・モデル照合は `preflight`、比較用OCR結果の集計は `postflight` です。
全体時間はスクリプトの計測開始から終了までで、最後の計測ファイル書き出しとBATのpauseは含みません。

メモリは当該PythonプロセスのWorking Setを250ms間隔と工程境界で採取した値です。
GPUメモリ、子プロセス、短い工程の厳密な瞬間最大値は含みません。
ページ別の値はCSV/JSONを参照してください。

比較は入力ハッシュ・入力順・設定・コード・モデル・SDK・主要依存パッケージを照合します。
独立したOCRで本文・座標・項目数に差が出た場合は「OCR結果が異なる比較」と表示します。
未完了や条件相違がある比較では速度改善の結論を出さず、参考値として扱ってください。
XDWのバイト列は生成情報等により異なるため、同一バイト列は要求しません。

同じ資料でA→B、B→A、A→Bの順に各3回実行し、中央値とばらつきを確認してください。
初回起動、OS/GPUキャッシュ、他プロセスの負荷は照合対象外です。総時間だけで方式差を判断せず、OCR時間と校正用XDWの作成時間を分けて見てください。
A/Bの同時実行はOSロックで拒否します。各実行が完了してから次を起動します。
異常終了後は再実行すると最初から新しい処理になります。

## 検証の区別

合成256ページのSDK検証はOCRを実行しない、XDW作成方式の検証です。
小規模XDWによるBAT検証は実際のOCRを実行しますが、合成資料を使います。
実際の200ページ超の業務文書とViewerでの表示・編集操作は、別途この環境で確認してください。
最終配布物の検証結果はRelease添付の `VERIFICATION_JA.md` を参照してください。
同梱の `README.txt` に通常のOCR・校正取り込み・Excel出力も記載しています。
