# docuworks-ctypes 1.0.0

## Stable release

- Promotes the verified 0.9.0 release candidate to the first stable release.
- Freezes public exports, Simple signatures, enums, units, save behavior,
  lifecycle behavior, and exception contracts in `PUBLIC_API_1.0.json`.
- Adds the 1.x stability policy and the no-change 0.9-to-1.0 migration guide.

## Compatibility

- Package behavior is unchanged from 0.9.0.
- The only Python-package source difference is the version value.
- OCR, OpenCV, CAD, AI, and database adapters remain outside this package.
