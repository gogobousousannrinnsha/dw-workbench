# Core 1.0.1

- Marker / Polygonの作成とPoints自然getterを、第1点基準の座標変換へ修正しました。raw getterは保存値をそのまま返します。
- Python 3.10でも、本体処理とcloseの二重失敗時に元例外を保持します。3.11以降の注記処理の失敗も元例外を置換しません。
- リンクCaptionに暫定的な255 bytesの入力防御を追加しました。指定コードページで符号化できる場合はその長さ、Unicodeへの切替が必要ならUTF-16LEの長さ（終端除外）で判定します。SDKの正式上限やあらゆる入力の安全性保証を意味しません。
- Captionは新規注釈作成前と既存setterで検査します。超過・埋込みNULはValueErrorとし、切り詰めません。
- Standard/Customの符号付き32bit整数の範囲、文字列・属性名・パスの埋込みNUL、非有限座標、位置と直線ベクトルの範囲をDLL呼出し前に検査します。User属性のbinaryはNULを保持できます。
- open_documentのauthはNONE/NO_DIALOGだけを受理します。AuthMode列挙値そのものは維持します。

## 互換性

公開関数の引数と戻り値、Raw ABIは変更していません。Viewerだけの制限は追加していません。
危険な長いCaptionと契約外入力は以前より早く拒否します。
旧版で作ったMarker/Polygonを自動修復しません。自然getterが返す値は保存済みの実座標に修正されるため、旧版で取得した値と異なることがあります。
直線の配置と丸め（始点と、終点−始点のベクトルをそれぞれROUND_HALF_UPで整数化）は維持します。
Annotationの位置・サイズは取得時点の保持情報です。自動サイズ変更後などはページから列挙し直して再取得してください。ハンドルは再オープン前後の永続IDには使用できません。

自動検証の対象はDocuWorks 10.1.1。9.1実機・Viewer操作・ネイティブDLLのCaption問題の原因究明は別段階です。
