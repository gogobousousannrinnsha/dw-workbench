# 台帳照合から注釈付きXDWへ：ローカル検証記録

2026年10月5日。`feat/local-review-navigation-20261005` の追加変更。既存Workbenchには確認済みの採用値・原本mm根拠と不変の確定結果がありますが、台帳の条件を参照して別項目の原文範囲へ注釈を出力する経路がありませんでした。確定結果を正本として参照し、台帳の一意な完全一致と1条件で判断して、新しい原本コピーへ塗りなし矩形を追加します。

元チェックアウト・既存Portable・公開側の35ファイルの変更には書き込まず、独立コピーで実装しています。既存Workbenchの2プロセスも終了していません。先に実装したOCR確認一覧・Workbench未完了移動の調査基準と検証は [既存の作業記録](LOCAL_FEATURES_20261005.md) を参照してください。

## 実装と責任

| ファイル | 役割 |
|---|---|
| `dw_workbench/ledger.py` | 標準ライブラリで.xlsxを固定読取。文字列・数値・数式・空欄などを区別し、数式や外部参照を実行しない |
| `dw_workbench/ledger_marking.py` | 固定結果と台帳の決定的照合、明示除外、保存再開検証、原本ID・SHA・実ページ・mm根拠による描画指示 |
| `dw_workbench/ledger_ui.py` | 型・条件・別の描画項目の選択、件数・台帳値・原文切り抜き表示、保存・再開・キャンセル・二重実行抑止 |
| `dw_workbench/annotation_writer.py` | 専用SDK子プロセス、固定原本のコピー、既存注釈保存、注釈のID・色・幅・位置の保存再読込検証、完成出力の確定 |
| `dw_workbench/ui.py` | 出力履歴の入口、処理中の案件切替・終了の保護 |
| `tests/test_ledger_marking.py` | 照合・入力変更・コピー途中の異常・重複防止など23ケース |
| `tests/test_v020_ui.py` | 新機能の実Tk試験2ケースを追加。既存試験も継続 |
| `docs/LEDGER_MARKUP_JA.md`、`docs/WORKBENCH_JA.md` | 利用・保存・再開・初版の範囲 |

照合は採用値やDB版を変更しません。描画にExcel行番号や画面位置を使用せず、確定した人の根拠を使用します。台帳にID列などを追加しません。SDK最小3mmの枠拡張でも、元の根拠は注釈属性・レポートに残します。

出力は既存結果へ追記せず、毎回固定原本から新しい文書別コピーを作ります。要確認を理由なしに飛ばしません。回転ページ、数式、曖昧な重複、型の不一致は自動出力しません。初版は1シート・1キー・1条件・塗りなし矩形で、追加の読取依存パッケージはありません。

証跡・合成案件・BAT・ローカルwheelは作業コピーと並ぶ `evidence`、`ledger-demo`、`artifacts` に保存しています。実帳票を試験入力に使用していません。

配布試験の失敗はWorkbench起動BATがOCRの厳密な配布一覧に含まれない既存問題です。今回の出力機能と分け、ガードや試験を緩めていません。OCR単独788件・Core136件の先行成功は既存の作業記録にあります。この追加ではOCR・Coreソースを変更していません。

このPCではDocuments配下の新規ディレクトリrenameがWinError 5になるため、出力はINCOMPLETE.txtを保持しながら新規フォルダーへ排他的にコピーし、ハッシュと入力を再検証してからマーカーを削除します。異常時には今回のコピーだけを破棄します。PC停止でマーカーが残った場合は完成品として扱いません。

pip／setuptoolsの0700一時フォルダーもホストで拒否されたため、wheel生成の証跡用プロセスのみ通常のmkdirを利用しました。製品コードや既存アプリ、OSの権限設定を変更していません。型チェッカーの設定・ツールは確認できず、静的型チェックは未実施です。

push、PR公開、merge、Release、配布、外部送信は行っていません。次は差分レビュー、開発Workbench／独立公開Workbenchへの反映先確認、版更新、既存配布一覧問題の解決、別Portableの組立・集約チェック・移動、Viewer／現地受入れを行ってから公開してください。元の公開側の未コミット変更を混ぜないでください。
