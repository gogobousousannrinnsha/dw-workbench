# Core 1.0.1 課題対応台帳

SDK契約を維持し、今回の完了範囲は修正と自動検証です。9.1実機とViewer操作は別段階です。
過去の静的調査は履歴として保持し、現在の判定はこの台帳と実測記録を優先します。

|ID|今回の対応|残る確認|
|---|---|---|
|G01|第1点基準の作成・取得、独立Raw照合・保存再読込・画像比較|9.1・Viewer|
|G02|元例外保持、Python 3.10～3.13で二重失敗を回帰化。Integrationsの診断情報も3.10で保存|自然発生するclose失敗の保証ではない|
|G03|符号付き32bit検査をStandard/Customに追加|Raw直呼びは呼出側責任|

|G05|キャッシュ契約を維持、再列挙による取得を説明|自動同期を追加しない|
|G06|SDK定義の色パレットを維持、独自色のRaw保存例を比較|全24bit色・付箋・Viewerへの一般化なし|
|G07|フォント名と文字セットの保存を確認、自動補正なし|未インストールフォント・代替表示・Viewer|

|G11|Custom Unicode名・値の保存、NUL拒否|Viewer側の文字数境界|
|G12|Custom DATEのraw int32保持・範囲検査|Viewer日付表示範囲|

|G22|整数化後±240000の位置・ベクトル検査、NaN/Inf拒否|9.1|

|G25|Openでauth 2を早期拒否、enumは維持|その他APIのauth契約は別扱い|

RawのXDW_AddSystemFolder、XDW_CreateSfxDocument/W、XDW_GetPageTextInformation、XDW_GetTMInfo、XDW_SetTMInfoはABI確認と機能仕様の根拠を区別します。固定仕様書に専用節がないことを理由に動作を推測して変更しません。
ヘルプとSDKの矛盾は、保存値・SDK描画・Viewer操作を別々に記録し、未検証を解消済みとは扱いません。

開発CIの成果物保存容量上限は今回の対象外です。マージ・公開は別判断です。
