# v0.6.0 Pre-releaseの構成と検証方針

DW-OCR v0.6.0はCore 1.0.1 / Integrations 0.12.0を含みます。
v0.5.0のOCR・Reviewed取り込み2.0・矩形テンプレート・Structured・CSVに、
PC内で動くテンプレート作成画面を追加します。最終成果物の対象コミット・結果・ハッシュは
ReleaseのVERIFICATION_JA.mdとRELEASE_PROVENANCE.jsonを正とします。

## 新しい操作

「テンプレート作成.bat」から見本のReviewedを選び、作業用XDWをViewerで開きます。
矩形を描いて保存・再読込した後、画面で項目名・用途・適用条件・出力順を設定します。
取得結果を確認して登録すると、templates/<名前>/v001へ見本付きで保存します。
途中の作業はtemplate-draftsへ自動保存し、登録後の変更は新しい版として保存します。
Viewerでカスタムプロパティを手入力する必要はありません。

詳細は[作成と改訂の手順](../user/template-editor.md)を参照してください。
適用・Structured保存・CSV出力は既存CLI/APIを使います。
矩形を描く専用画面、適用・CSVのGUI、XLSX、原本へのマーカーは今回の追加対象外です。

## 保存と互換性

- Canonical・Reviewed・登録済みテンプレートは上書きしません。
- テンプレート形式1.0を維持し、authoringに改訂用の見本・設定を追加します。
- templates全体を別のPortableへコピーして改訂できます。見本も含まれるため共有範囲に注意します。
- 従来のauthoringなしテンプレートも利用できます。最初の改訂時に対応するReviewedを選択します。
- 下書き・利用者のテンプレート・実文書は配布物に含めません。
- 旧Portableを保持し、新しい短い書込み可能なフォルダーへ展開します。

## 配布の組み立てと受け入れ

1. 開発ソースを固定し、既存公開版のMITと第三者条件を維持して公開用ソースへ変換します。
2. Integrations 0.12.0のsdistからwheelを作り、監査・独立導入・未加工sdist試験を行います。
   Core 1.0.1は公開済みの同一配布物を使用します。
3. 検証済みv0.5.0 Portableを基準に自作部分を更新し、第三者資産・GPU構成を維持します。
4. 新規展開先でGPU OCR、Reviewed取り込み、テンプレート適用、CSVを確認します。
   作成画面は合成文書とSDK操作を使い、作成・再開・登録・改訂・移動後利用を確認します。
5. 分割復元・全ファイルのハッシュ・利用者データの除外を確認し、添付物を固定します。
6. 新しいタグとPre-releaseを公開し、匿名再ダウンロード・復元・起動を確認します。

同梱Python 3.13.15、Tkinter/ttk、Pillowを使用し、追加インストールは不要です。
開発時の自動試験と最終Portableの検証は分けて記録します。
Viewerの手操作、Excel画面、現地実帳票、DocuWorks 9.1は未確認として明示します。
既存Release・タグ・添付物は変更しません。
