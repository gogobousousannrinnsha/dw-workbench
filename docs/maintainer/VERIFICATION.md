# 構造整理の検証記録

対象はCore 1.0.0 / Integrations 0.7.0、基準は開発main 26ebf04です。公開済みv0.3.0の差し替えではなく、未公開の整理候補です。

| 検証 | 結果 |
|---|---|
| Python 3.11 / 3.12 / 3.13、Integrations回帰 | 各285件成功 |
| Python 3.10、訂正・レビュー・共通プレビュー | 158件成功。ライブラリ全体の3.10確認ではない |
| 配布処理の回帰・管理元検証 | 80件成功 |
| Python 3.13、SDK保存・再オープン | 28件成功 |
| 通常pipで導入した独立wheel環境（3.11） | pip install / pip check成功、回帰285件成功 |
| 開発用・公開用の未加工sdist | 各156件成功、外部ファイル補完なし |
| 公開用wheel・sdist・既存Core配布物 | 4配布物の内容監査成功 |

wheel試験はリポジトリから分離したテストコピーで行い、機能本体のimport先が導入済み環境であることを確認しました。pytest・jsonschema・Pillowなどの試験依存は既存のPython 3.11試験環境から利用しています。機能パッケージの導入は通常のpipです。

このホストではPython 3.13のビルド用一時フォルダーにアクセス制限があるため、Python 3.11で既存のbuild/setuptools等を参照してビルドしました。ネットワークからのビルド依存導入は証明書検証で失敗したため採用していません。製品コードや保護設定を変更する回避は行っていません。

初回の公開sdist検証では、試験中の展開先をwheelビルドにも使ってしまい、展開内容の不変性チェックが失敗しました。その結果は採用せず、新規展開先で試験だけを実行し、156件成功と不変性を確認しました。最終成果物のビルド用展開先と試験用展開先は分離します。

Core機能本体と既存docs/evidenceは変更していません。共通プレビューの移設では、原画像、座標、日本語・改行・区切り文字、空ページ、旧入口の互換を確認しました。

Portableの実機試験・保存済みViewer文書の取り込み・最終ハッシュ一覧は、候補と同じ納品フォルダーの「確認結果.txt」と検証JSONに記録します。この文書の試験は過去版のViewer手操作を新たに実施したという意味ではありません。複数領域Viewer異常操作は引き続き未確認です。
