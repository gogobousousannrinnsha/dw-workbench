# 操作の流れと保存・確認・出力

上部の工程ボタンから、必要な操作へ直接移動できます。順番を強制するウィザードではありません。ページごとの作業、複数ページの一括処理、途中再開、前の工程へ戻る操作を利用できます。

「現在」は今の作業画面とページ、「案件全体」は未確認項目・読取設定のない対象・寸法不一致スキップ・登録待ち・確定結果の件数です。右の主ボタンは現在の状態に合った操作を表示します。ボタンが無効の場合は必要な操作を案内します。個別の主ボタンにマウスを置くと、その操作と無効理由を上部に表示します。

| 工程 | 操作と結果 |
|---|---|
| 1 文書登録 | 案件を作成／再開してXDWを追加。元の文書を保持し、案件内へ固定コピーを登録 |
| 2 読取設定 | 文書・対象ページ・読み取りテンプレートを選んで適用。必要なら「範囲」で新しく作成、または「共通」から取込 |
| 3 OCR | 選んだ対象の文字の候補を作成。未編集の採用欄へ今回の結果を自動入力する。自動入力は未確認 |
| 4 確認・訂正 | 原文と値・単位・範囲を照合。正しければ「確認して次へ」、問題があればその場で修正 |
| 5 Excel出力 | 確認済みの結果を確定し、その時点の値・根拠を保存。新しいExcel／CSVを作成 |
| 6 台帳・注釈 | 保存した確定結果を台帳条件と照合。原文と判断のプレビュー後、原本コピーへ枠を付けたXDWを出力 |

文書・範囲・確認・出力・履歴・共通のタブは、いつでも利用できます。「範囲」と「共通」は読取設定に必要なときに開きます。「履歴」は過去の確定結果や失敗した形式の再出力に使います。台帳照合は「出力」から直接進めます。

## 似ている言葉の違い

- **保存**：入力内容を残すこと。入力は自動保存します。保存しただけでは原文を確認した扱いになりません。
- **確認済み**：人が原文と照合して、この項目を確認した状態。値・原文・単位・範囲を変えた項目は再確認が必要です。
- **確定**：確認済みの結果と原本の範囲を、その時点の変更しない結果として保存すること。後の訂正は過去の確定結果を変えません。
- **出力**：確定結果からExcel／CSV、または台帳照合の判断から注釈付きXDWの新しいファイルを作ること。生成失敗でも保存した結果は保持し、再出力できます。

任意項目の理由付き対象外は既存の完了規則に従います。確認が完了していない対象を含む案件でも、完了した記録だけを明示して確定する既存操作を利用できます。画面の案内はこの判断を変更しません。

## OCR結果の自動入力と確認（ローカル修正版）

テンプレートを適用してOCRを実行すると、未編集の項目へ今回の認識結果を自動入力します。表示中の記録のOCRを指示し、そのまま待っている場合は、入力済みの確認画面と採用欄へ移ります。正しければ「確認して次へ」で原本を検証して確認済みにし、次の未完了項目へ進みます。問題がある値はその場で修正できます。自動入力だけでは確認済み・確定・出力可能にはなりません。

手入力、候補の手動取り込み、意図的な空欄化、原文転記・単位・範囲・理由の変更、確認・保留・対象外指定をした項目は再OCRで上書きしません。既に自動入力した値も再OCRで置き換えません。新しい結果は候補履歴で確認し、必要な場合だけ選んで取り込みます。文字列の先頭ゼロ・表記と原本の実ページ・mm座標を保持し、数値は既存の規則で検査します。文字がない・不正な数値・曖昧な候補は要確認として残します。複数の認識行は一つの候補の構成要素で、古い再OCR候補の件数だけでは初回入力を妨げません。

OCR中に他の文書・項目・タブへ移る、入力を始める、フォーカスを別の操作へ移す場合は、自動の画面移動を取り消します。背景OCRは表示やフォーカスを奪いません。編集中の結果保存では先に人の入力を保存し、保存失敗では入力と処理結果を保持して再保存を待ちます。中断やテンプレート変更後の古い結果を自動採用しません。

入力の由来を記録内に追加しますが、案件DB・項目状態・確定結果は形式2のままです。旧案件の未編集版0は自動入力できます。項目単位の編集履歴を確認できない旧案件や、旧アプリで編集した記録は自動上書きを避け、必要に応じて候補を手動で取り込みます。案件を開くだけで移行・書換えは行いません。

## 寸法不一致をスキップする（ローカル修正版）

適用テンプレートと原本のページ数・寸法・向きが不一致の場合、OCR候補生成と「次の未完了項目」の通常移動からその対象を外します。表示中の不一致対象でOCR操作をした場合も、エラーダイアログを出さずに次の通常対象へ進みます。件数は上部に表示し、「寸法不一致の一覧」で文書・元ページ・理由を確認できます。この一覧を開いても作業画面を操作できます。

全対象が不一致の場合は空のOCRを開始せず、適合テンプレートの選び直しを案内します。ページ用テンプレートでは該当ページだけ、文書全体用ではその文書の記録全体が対象です。寸法の許容差（各辺0.01 mm未満）、向き、ページ数の既存判定は変更していません。未割当は作業待ちに残り、寸法不一致以外のエラーは通常のエラーとして表示します。

原本・保存した手入力・確認状態・過去の確定結果は保持します。必要なら不一致ページを一覧から直接開き、従来どおり手入力と文書固有の範囲指定で確認できます。人手で確認を完了した記録は従来どおり出力対象です。未完了の不一致は、既存の「完了分だけ出力」で除外を確認した場合に限り確定結果の除外一覧へ理由を残し、Excelの「出力情報」にも記載します。

適合する別テンプレート・別版を適用すると通常対象へ戻ります。変更前の記録は履歴に残り、新しい記録は未確認から始めます。複数文書の一括変更では、既存割当も変更するため「未割当だけに適用する」を外し、プレビューを確認してください。同じID・版の再適用は変更を行いません。保存形式の変更・過去結果の書き換えはありません。

## 戻る・再開・復旧

確認画面の下には「確認して次へ」「次の未完了項目へ」「出力へ進む」を固定しています。入力欄や候補一覧をスクロールしても主操作は見えます。項目一覧はその中で、入力画面は右端のスクロールバーやマウスホイールで移動できます。キーボードで入力欄へ移ると、その欄が見える位置へスクロールします。

保存に失敗した場合は入力と表示位置を保持します。先に再保存してください。上部の「管理・復旧」から、未保存内容の再保存、中断・失敗した処理の再開、実行中処理の中断、バックアップ、共通テンプレート管理へ進めます。実行中は確定・注釈出力などを無効にし、案内を表示します。中断は今回のアプリが扱う処理だけが対象です。

台帳画面は「1 台帳と照合条件」「2 原文と判定を確認」に分けています。条件の保存・照合後は原文確認へ移動します。条件へ戻って変更すると再プレビューが必要です。注釈出力のボタンは下に固定し、要確認や対象なしなどの無効理由を表示します。「保存した照合を再開」から、条件・除外理由を再開できます。

## キーボード

| キー | 操作 |
|---|---|
| Alt+1～6 | 上部の対応する工程へ移動 |
| Ctrl+S | 保存を再試行。確認済みにはしない |
| Ctrl+Enter | 表示中の項目を確認済みにして次の未完了へ進む。入力未選択・値なし・閲覧専用・処理中では実行しない |
| Tab／Shift+Tab | 操作・入力欄を移動。スクロール内の欄は見える位置へ移動 |
| PageUp／PageDown | 入力画面をスクロール。一覧にフォーカスがある場合は一覧自身の操作 |

## ローカル試用

作業フォルダーの「操作導線を改善したWorkbenchを起動.bat」で、独立した `ui-demo` の合成案件を開きます。既存Portableのruntimeを借り、追加版ソースを実行します。既存Portableのプログラムを置き換えません。OCRモデルを含まない合成環境では手入力の案内になります。

「出力」→「台帳を選び、照合プレビューへ進む」→「保存した照合を再開」でサンプルの照合を開き、原文・除外理由・原本位置を確認できます。詳しい台帳規則は [台帳照合の手順](LEDGER_MARKUP_JA.md) を参照してください。

実際の合成画面は、作業フォルダーの `artifacts/ui/画面と操作ガイド.html` とその `screenshots` に保存しています。通常の1000×650画面と文字拡大の確認画面を含みます。Windowsの全DPI・全モニター・実帳票の受け入れを保証するものではありません。
