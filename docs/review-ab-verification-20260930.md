# 校正用XDWのA/B検証版 — 検証記録

公開版v0.6.1（`ae4c27a46a7bc0a628ff7beb9a750a5b234de88f`）を基準にしたローカル検証版。
Core 1.0.1、Integrations 0.12.0+reviewab.1、Python 3.13.15、DocuWorks API 10.1.1。
実OCRはRTX 3060 12GB、Paddle GPU 3.2.2、PaddleOCR 3.7.0、PP-OCRv6 mediumで確認した。

## 提供物

- 共通Portableに `A_一括作成.bat` と `B_ページ別作成と結合.bat` を収録。どちらも元のXDWからOCRする。
- `比較結果作成.bat` は実行フォルダー2つを指定して工程別比較を出力する。
- 操作方法はPortable内の `README_AB.md`。ソース差分は `reference/tracked-changes.patch`。
- 静的ファイルの照合一覧は `reference/distribution-files.json`。入力・出力・キャッシュ等の可変領域は対象外。
- 検証用データと計測記録は親フォルダーの `validation`。起動試験の生成物は `validation/portable-smoke/results` に退避し、PortableのINPUT・OUTPUT・runsを空にして提供する。

## 確認できたこと

1. 同じ識別情報を使った比較で、変更前の公開版、A、Bの保存後データが一致した。白紙ページと異なる用紙サイズを含む。
2. 256ページ・各20項目、計5,120項目の合成データでA/Bとも作成・保存・全ページ再読み込みに成功した。本文・位置・寸法・色・塗りつぶしなし・フォント・方向・回転・改行設定・文書/ページ/注釈の識別情報が一致した。
3. SDKで文字を編集し、A/B両方をstrictモードとidentityモードで取り込めた。Canonicalが変更されないことも確認した。
4. 白紙作成、文字配置、保存、結合の失敗と中断を注入し、未完成セッションが確定されないことを確認した。
5. 実際のBATで3ページの合成XDWをOCRし、A/BともCOMPLETE。共通の校正結果取込BAT、比較結果作成BAT、同時実行ロックも成功した。実OCR結果は両方式とも3ページ・6項目で一致した。
6. Integrationsの回帰試験628件、配布/Portableの回帰試験102件を通過。その後、比較スクリプトの試験を配布側へ移し、修復BATの固定バージョン試験を追加した。最終構成の追加関連試験10件も通過した（重複を除く試験項目は731件）。
7. ソース内容監査、Core/Integrationsのwheel・sdist計4アーカイブの内容監査、候補Portableのpip checkに成功した。

機械可読の記録：`validation/small/validation.json`、`validation/portable-smoke/validation.json`、`validation/artifact-checks.json`。

## 大容量の参考計測

以下は**実OCRを行わない合成256ページのSDK試験**。単位は秒。
同一入力、実行順はA初回 → B → 小規模の追加確認 → A再計測。反復回数が揃った性能試験ではない。

| 工程 | A初回 | B | A再計測 |
|---|---:|---:|---:|
| XDW本体作成 | 231.614 | 154.953 | 195.111 |
| うち白紙作成 | 97.922 | 9.163 | 64.554 |
| うち文字配置 | 112.466 | 111.741 | 109.799 |
| うち結合 | 0.082 | 0.170 | 0.080 |
| うち単ページ保存 | — | 20.791 | — |
| うち最終保存 | 20.917 | 0.664 | 20.466 |
| 完成後の全ページ検査 | 15.230 | 15.148 | 15.415 |

Bの本体作成は今回短かったが、主な差は白紙作成で、A自身にも変動がある。文字配置時間はほぼ同じであり、ページ別作成にすれば必ず高速化する、あるいはOCRが速くなる、とは判断しない。
3回の保存後データのSHA-256は一致：`96c1078817c6757da28c77859c1d1aaae14bd17c4513115296ceab4a0a25f94a`。
これは内容・属性を正規化した検査データのハッシュで、XDWファイルのバイト一致を意味しない。
記録：`validation/large-A`、`validation/large-B`、`validation/large-A-repeat`。

小規模の実OCR試験は、全体A 78.810秒/B 13.670秒、OCR工程A 72.954秒/B 11.189秒だった。
初回処理等の影響を含むため、総時間差をXDW作成方式の効果として扱わない。
業務文書で比較する際はA→B、B→A、A→Bの各3回を実行し、工程ごとの中央値とばらつきを確認する。

## 未確認の範囲
