# 複数文書へテンプレートを一括適用する

DW-Workbench v0.3.0候補の追加機能です。同じ案件に登録した複数の文書へ、同じテンプレートをまとめて適用します。

## 操作の流れ

1. 案件を開き、対象のXDWを追加します。文書の登録処理が完了するまで待ちます。
2. 「作業一覧」タブの「複数文書へ一括適用」を押します。
3. 登録済みのテンプレートを選びます。文書全体用とページ用を選択できます。
4. 一覧で対象文書を複数選びます。Ctrlキーで追加選択、Shiftキーで範囲選択できます。「全選択」で案件内の登録済み文書を選べます。
5. ページ用では、全ページ・ページ範囲・奇数ページ・偶数ページを選びます。範囲の例は `2-5,8` です。同じ指定を各文書に適用します。文書全体用ではページ指定は不要です。
6. 「プレビュー」を押し、文書・ページ・適用内容・見送る理由を確認します。一覧の行を選ぶと理由の全文を表示します。
7. 「この内容を適用」を押します。適用結果の件数が表示されます。

テンプレート適用後は候補生成、原本との照合、確認を行います。**一括適用だけではOCRを開始しません。** 確認が完了した記録は、従来どおり案件ごとにまとめてExcel／CSVへ出力できます。

## 既存の記録を保護する

「未割当だけに適用する」は初期状態で有効です。テンプレート適用済み、または対象外にしたページ・文書は見送ります。案件内の未割当へまとめて適用したい場合は、「全選択」と組み合わせます。

このチェックを外すと、既存の割当も対象にできます。同じテンプレートID・版の再適用は記録を変更しません。別テンプレートや別版への切替では、以前の記録を履歴に残し、採用値が空の新しい記録を作ります。以前の採用値と確認状態は新しい記録へ引き継ぎません。対象外指定も切り替わるため、プレビューで対象を確認してください。

## プレビューで見送られるもの

- 未割当だけが有効な場合の、適用済み・対象外の対象。
- 処理単位が固定され、選択したテンプレートの「ページごと／文書全体」と一致しない文書。
- 文書に存在しないページ番号、指定条件に合うページがない文書。

全割当が未割当の文書は、適用時にテンプレートに合わせて処理単位を初期化・変更できます。プレビューに変更内容を表示します。

ページ寸法や向きなどが合わない場合も、必要項目を作成します。ローカル修正版では、その対象をOCR・通常確認の移動からスキップし、件数と理由を表示します。自動読み取り用の根拠範囲は設定しません。適合テンプレートへの変更、または文書固有の範囲指定と手入力による個別確認を利用できます。未完了の不一致は既存の「完了分だけ出力」の除外一覧に理由を残します。プレビューの警告を確認してください。

## 保存と再確認

プレビュー後に対象記録が更新された場合は、古いプレビューからの適用を拒否します。もう一度プレビューしてから適用してください。対象選択・テンプレート・ページ条件などを変えた場合も、プレビューを作り直します。

適用する対象の更新は一つの保存処理で行います。保存に失敗した場合は、今回の適用を全体で取り消します。プレビューで見送りと表示された対象は、この保存処理に含めません。

元のPortableや案件は保持し、新しい候補を別フォルダーで使用してください。既存案件を候補で開く場合は、先に案件バックアップを作成し、そのコピーで確認できます。案件の保存形式はv0.2.0と同じです。
