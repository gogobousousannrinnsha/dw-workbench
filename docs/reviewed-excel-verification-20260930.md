# Reviewed全文Excel出力の検証記録

公開v0.6.1を基準とするA/B検証候補へ追加した、ローカル専用候補です。Core 1.0.1、Integrations 0.12.0+reviewxlsx.1、XlsxWriter 3.2.9を使用します。main反映、タグ作成、Release公開は行っていません。

## 追加内容

`全文Excel出力.bat`からReviewedフォルダーを選択し、隣の新規xlsxへ出力します。フォルダーまたはreviewed.jsonの引数指定にも対応します。
通常テキスト1項目1行と文書・ページ情報の2シートが基本です。長文は項目ID・分割番号付きで切り分け、シート行数上限では続きのシートを作成します。
Reviewed 1.0/2.0、一括・分割由来の結果に対応します。本文・改行・前後空白・空文字・重複を保持し、数式・数値・日付・リンクへ自動変換しません。
APIとCLI、任意依存xlsx、オフライン修復用wheel・ライセンスを同梱します。操作は[user/reviewed-excel.md](user/reviewed-excel.md)を参照してください。

## 大規模な合成データ

新しいPortableのPythonで、256ページ・100,000項目のReviewedを出力しました。SDK境界を模擬して作った合成データであり、実際の業務文書ではありません。

| 項目 | 結果 |
|---|---:|
| 入力読込 | 2.082秒 |
| Excel出力API（再検証・保存・最終検証を含む） | 17.742秒 |
| 読込から出力完了 | 19.824秒 |
| プロセスRSS最大観測値 | 1,011,142,656 bytes（約964 MiB） |
| xlsxサイズ | 7,855,512 bytes |
| 出力項目・行数 | 100,000 |

本文、ページ、順序、位置・寸法、書字方向、回転、項目IDと全ページ情報が再読込結果と一致しました。入力ハッシュも変化していません。
メモリは100ms間隔と処理境界で測定した当該PythonプロセスのRSSです。独立読込ライブラリは測定終了後に読み込みました。厳密な瞬間最大値ではありません。
書込は行単位ですが、既存Reviewed読込・検証は全文JSONをメモリに展開します。処理全体のメモリ一定性は主張しません。
測定は1回であり、文書内容・環境によって時間とメモリは変わります。
