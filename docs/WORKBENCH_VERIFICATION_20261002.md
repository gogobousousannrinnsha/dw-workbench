# DW-Workbench v0.1.0 検証記録

初版の業務モデル、保存、画面、範囲OCR、確定結果、Excel／CSV、履歴、バックアップ、Portableを実装しました。
成果物はローカル検証候補です。実帳票の確認と公開は実施していません。

- 開発基準: `df867033ce6ca9419fec623a4cc0fbf65f3fbfb6`。専用worktreeで実装し、既存の開発場所・Portableを保持。
- 基準配布ZIP SHA256: `976b4c692d475a53151c37805cd73623eedb51a2f40cdc0828fa62a892cc7a1a`。
- 最終wheel SHA256: `422f118777baa52b936bfb9fa646440fec296c3a775ce3c45045300668f3333c`。
- 実機: DocuWorks 10.1.1、NVIDIA GeForce RTX 3060。Python 3.13.15、Tk 8.6.12。
- 同梱資産18,391ファイルを基準ZIPとSHA256で照合。モデル・第三者ライセンスを保持。

| 区分 | 確認内容 |

## 負荷計測と限界

同じ構成の合成10ページ文書を100件登録し、1,000ページを描画、3,000項目を読み取り・訂正・確認しました。
部品番号001234、設定温度25.0℃、測定温度23.0℃の期待値との不一致はありませんでした。
確認操作は合成期待値を使う自動操作です。実帳票精度・手動操作の保証ではありません。

| 処理 | 計測結果 |
|---|---:|
| 描画1,000ページ | 合計331.730秒、平均0.332秒／ページ |
| 範囲OCR3,030回（再OCR30回を含む） | 合計151.055秒。初回7.675秒、以降平均約0.047秒 |
| 訂正・確認3,000項目 | 合計27.397秒 |
| Excel／CSV生成 | 0.688秒 |
| 案件再開・整合性検査 | 0.126秒 |

これらは正常系の負荷計測です。その後、キャッシュ破損検出・接続終了・画面の外での原本検証を仕上げています。
最終版でも100記録・3,000項目の再開・確定・出力を確認し、移動先の実行版を各JSONへ記録しています。
完了単位で採取した最大RSSはアプリ約62MiB、DocuWorksワーカー約39MiB、OCRワーカー約1.60GiBです。
処理途中の瞬間最大とGPU VRAMは測定していません。画像は必要ページ単位で処理します。

スクリーンショット取得はこの実行環境では失敗したため、見た目の手動確認済みとは扱いません。
現地帳票の「設定作成→別文書適用→訂正・確認→中断・再開→出力→履歴から根拠確認」と、9.1互換性は未検証です。
