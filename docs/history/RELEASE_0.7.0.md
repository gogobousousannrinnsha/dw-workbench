# Integrations 0.7.0 / Portable v0.3.0

機能基準d31c2cbを正式版0.7.0へ昇格します。Coreは1.0.0、Canonical OCR Resultは1.0/1.1互換を維持します。
文字訂正の別保存・検証・適用・JSONL出力、原本重ね合わせ型の1ページ・1領域/複数領域XDWレビューが対象です。
公開Portable v0.3.0はPre-releaseです。通常のOCR操作入口は従来どおりで、新機能はPython APIとして利用します。

## 使い方

- [文字訂正API](../CORRECTIONS_0.7.0.md)
- [1領域XDWレビュー](../REVIEW_XDW_0.7.0.md)
- [複数領域XDWレビュー](../REVIEW_XDW_REGIONS_0.7.0.md)
- [訂正例](../../examples/correct_saved_ocr.py)
- [複数領域の例](../../examples/use_review_xdw_regions.py)

元runを明示して領域IDを選び、確認XDWを別保存します。編集後は候補を既存の修正保存・適用APIへ渡します。
同一文字の領域を文字列や位置で照合せず、識別属性を検証します。元run・原稿座標・信頼度は変更しません。
通常のJSONL出力は元結果のままです。訂正後の出力にはexport_effective_jsonlを使います。
白紙型、複数ページ確認XDW、検索、テンプレート、再OCR、領域構造編集は対象外です。

## Viewerと公開成果物の区別

1領域の6ケース、複数領域の正常1ケースについて、既存の利用者報告と保存後照合の記録を継承します。
今回の昇格でViewerの手操作を再実施したという意味ではありません。複数領域のViewer異常操作と白紙型は未確認です。
公開する機能本体・Schemaは開発版と全ファイル照合し、公開用ライセンス・配布説明の差分は別管理します。
第三者ランタイム・モデル・公開Core配布物はv0.2.0から維持します。旧版は残して新規フォルダーへ展開してください。

開発mainの統合コミット、公開コミット、最終PortableのサイズとSHA-256、実機試験と公開後取得確認は、
v0.3.0のReleaseに添付するRELEASE_PROVENANCE.jsonとVERIFICATION_JA.mdに記録します。

公開CIの英語Windows環境で訂正例の表示に文字コードエラーを検出し、表示不能な文字のみエスケープするよう修正しました。訂正JSONLの日本語データは保持されます。UTF-8とcp1252を試験しています。

ジョブ・矩形・確認画像の来歴に残っていた旧版の固定値を修正し、実行パッケージの版を記録します。戻り値と保存済みジョブ、派生物の報告で0.7.0が記録されることを回帰試験に含めています。
