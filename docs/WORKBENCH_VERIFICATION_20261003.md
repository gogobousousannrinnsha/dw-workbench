## 実SDK／GPUの通常負荷

DocuWorks **10.1.1**、NVIDIA GeForce RTX 3060で、合成XDW **100文書×10ページ×30項目／ページ**を処理しました。

| 検査 | 結果 |
|---|---|
| SDK描画 | 1,000ページ |
| 負荷用の実GPU OCR | 30,000範囲、不一致0件 |
| 再OCR・中断・白紙範囲を含む実OCR | 30,032回 |
| 確認値 | 1,000記録、30,000項目 |
| 独立した出力読取 | XLSX／CSV各1,000行、根拠30,000項目 |
| 再OCR、中断再開 | 採用値・確認状態不変、未保存ジョブを再開 |
| 原本、バックアップ、再読込 | ハッシュと確定結果の一致 |
| 全体所要時間 | 約41分9秒 |
| 描画中央値 | 約346ms／ページ |
| OCR呼出中央値 | 約52.3ms／範囲 |
| 最初のモデル準備を含む最大OCR呼出 | 約7.87秒 |
| 訂正・確認保存の中央値 | 約8.94ms／項目 |
| XLSX／CSV生成・検証 | 約9.99秒 |

250ms間隔のRSS測定では、アプリ約204MiB、DocuWorksワーカー約106MiB、OCRワーカー約2.23GiBでした。
これは測定で捉えた最大値です。瞬間最大やGPUのVRAM量を表しません。

この長時間負荷のwheelは`3d1ed705dc9d048bd6ef3e29208bf0e3b5f87b9c09c7af094775b220dcedf8a8`です。
終了後、画面更新・診断分離・保存再試行・パス拒否・出力失敗処理を含む最終wheelへ更新しました。
長時間負荷の証跡と最終wheelの証跡は分けて保存しています。

## 画面更新の測定

GUI専用の100文書・1,000ページ・30,000空項目で測定しました。XDWは無効な試験用バイト列で、SDK描画・OCRの速度や精度の試験には使用していません。

| 操作 | 変更前 | 最終ソース |
|---|---:|---:|
| 一回の進捗更新の中央値 | 386.75ms | 12.45ms |
| DB問い合わせ | 4,393 | 127 |
| イベント応答の最大間隔 | 432.8ms | 36.38ms |
| 選択項目のOCR候補更新 | 案件全体を再読込 | 約0.133ms、1問い合わせ |

OCR候補追加は確認状態を変えないため、表示中の候補だけを更新します。
手入力・確認では該当文書の進捗を更新し、未保存の値・原文・根拠・候補選択を保持します。
