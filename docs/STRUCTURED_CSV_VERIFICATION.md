# Structured Result CSV出力の検証（2026-09-22）

対象: Core 1.0.1 / Integrations 0.11.0 開発候補。
仕様と操作例は[CSV出力](STRUCTURED_CSV.md)を参照。

| 検証 | 結果 |
| --- | --- |
| CSV専用試験 | 37件成功 |
| Integrations全体とscriptsのDLL不要試験 | Python 3.13.15で673件成功。CSV専用試験を含む |
| 作成したsdistの展開元から実行 | 446件成功、元ファイルを変更せず実行 |
| Core/Integrationsのwheel・sdist | 4ファイルの作成・内容監査・メタデータ検査が成功 |
| ソースツリー外へインストールしたwheel | SDKなしで正常・要確認・適用不可の3件をCSVへ出力 |
| 非日本語Windows相当の標準出力 | cp1252の環境で日本語の結果表示・終了コード0/2を確認 |

CSV専用試験は、旧Reviewed 1.0と新2.0から作った実際のStructured Result保存形式を使う。
SDK部分だけを模擬し、Structuredの検証・抽出再計算・CSV保存・再読込みは実装を実行した。

確認した契約:

- UTF-8 BOM、全項目の引用符、レコード区切りCRLF。
- 先頭ゼロ、指数・日付に見える文字、単位、Unicode、カンマ、引用符、混在する改行の保持。
- 取得項目の順序、固定列名との衝突、適用不可だけの場合の列保持。
- 候補なし・空文字・空白のみ・回転・縦書き・由来情報の不正・ページ不一致の表示。
- 同じ結果IDの重複、異なる登録テンプレート、同じIDで定義の異なる版、文書名の不足などの拒否。
- 原本・Session・テンプレート・Structuredの不変性、元フォルダーなしの独立出力。
- 出力前の破損、読込み後の変更、途中書込み・確定失敗、出力先が先に作られる競合への対処。
- 日本語CLIの終了コード0/2/1と既存CSVの上書き拒否。

試験データと出力例は合成データで、実帳票を利用していない。
CSVをPythonのCSV読込機能で検証した。Excelの画面操作、現地運用、Portableへの組込みは
今回実施していない。今回の機能はSDKを利用しないため、新しいSDK実機試験は追加していない。
Python 3.10～3.13とパッケージ検査のCI結果は、この変更のPRチェックを参照する。
