# OCR確認一覧（ローカル開発候補）

元OCR結果の中から、先に照合したい領域を一覧にします。OCR・原本・Reviewed・訂正内容を変更しません。

更新したPortableでは「OCR確認一覧.bat」を実行し、`manifest.json`のある元OCR結果フォルダーを選択します。
フォルダーまたは`manifest.json`をBATへドロップする方法も使えます。キャンセルはファイルを作らず終了します。
元結果の隣に日時とID付きの新しいJSONを保存し、画面に対象のページ・領域ID・文字を表示します。

既定の閾値は0.8で、**閾値未満**の領域と、信頼度の記録がない領域を選びます。閾値と同じ値は低信頼度には含めません。
信頼度は認識器のスコアで、正しい文字であることや人が確認済みであることを示しません。高いスコアの箇所も原本照合が必要です。
文字未検出ページと未処理ページを別々に表示します。文字未検出は白紙であることの判定ではありません。
元結果に総ページ数がない場合、未処理ページは`null`（不明）です。

JSONには実ページ、領域ID、原文、原本SHA256、manifest SHA256、元のmm矩形・四隅を保持します。
`image`は**元OCR結果フォルダーからの相対参照**です。表示倍率・スクロール位置から座標を生成しません。
この一覧は派生出力です。JSONを編集してもOCR結果や校正結果には反映されません。

閾値や保存先を指定する場合は既存のCLI入口で実行できます。

```bat
docuworks-integrations.bat review-report --run-dir "元OCR結果" --threshold 0.9 --output "確認一覧.json"
```

保存先は元結果の外にある新しいファイルにしてください。既存ファイルは上書きしません。
入力のハッシュ検査と一時ファイルの再読込が成功した後に確定するため、中断・失敗で不完全な一覧を確定しません。
既存の公開PortableへBATだけを足しても動きません。対応するIntegrationsのコードと起動スクリプトを含む別候補を組み立ててください。
