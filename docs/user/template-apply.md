# BATでテンプレートを適用する

校正結果へ登録済みテンプレートを適用し、項目ごとの値をStructured Resultへ保存します。既存の`apply-template`コマンドを呼び出す入口です。

## 対応するPortable

Portable v0.6.1には、このBATと補助スクリプトを同梱しています。展開後、そのまま操作できます。Core 1.0.1 / Integrations 0.12.0を使用します。

旧版v0.6.0へ追加セットを導入する場合だけ、次の2ファイルを同じ位置へコピーしてください。追加セットだけでは起動できません。同梱Pythonやwheelの更新は不要です。

```text
Portable/
  OCR開始.bat
  テンプレート適用.bat        ← 追加
  runtime/python.exe
  scripts/apply_template.py   ← 追加
```

## 操作

1. `テンプレート適用.bat`をダブルクリックします。
2. 校正結果取込で作成した、`reviewed.json`のあるフォルダーを選びます。編集用のXDWやreview-sessionフォルダーではありません。
3. `template.json`のある登録版フォルダーを選びます。作成画面で登録した場合は、例えば`templates/帳簿A/v001`です。`templates`全体や下書きは選びません。
4. 画面に表示された取得値、判定、保存先を確認します。

保存先はBATの置かれたPortable内の`structured/result-日時-ID/`です。毎回新しいフォルダーになり、過去の結果と入力文書は上書きしません。

校正結果フォルダーをBATへドロップした場合は、テンプレートだけを選択します。引数で指定するときは、校正結果、テンプレートの順です。それぞれ`reviewed.json`、`template.json`そのものを指定しても構いません。

```powershell
.\テンプレート適用.bat "OUTPUT\job-例\doc-000001\reviewed\result-例" "templates\帳簿A\v001"
```

| 表示 | 保存と次の操作 |
|---|---|
| 取得完了 | 抽出結果を保存。項目の値と表示された確認事項を確認する |
| 要確認 | 診断付き結果を保存。欠落・文字方向などの確認事項を確認する |
| 適用不可 | 診断付き結果を保存。選んだ文書・テンプレート・適用条件を確認する |
| 抽出に失敗しました | 今回の完成結果は作られない。入力やエラーを確認する |
| キャンセルしました | 結果を作らず終了する |

1回に1文書・1登録版を適用します。テンプレートや最新版の自動選択、CSV出力は行いません。CSVにまとめる場合は、保存された結果フォルダーを[CSV出力](template-csv.md#5-csvへまとめる)の入力にします。

適用処理はSDK/GPUを使いません。選択画面はPortable同梱のTkinterを使います。終了コードは0が取得完了または選択キャンセル、2が要確認・適用不可、1が処理失敗、130が操作中断です。
