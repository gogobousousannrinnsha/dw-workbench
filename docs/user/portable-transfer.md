# 別のWindows PCで使う

配布候補はDW-OCR v0.8.0、DW-Workbench 0.4.0、Core 1.0.1、Integrations 0.14.0です。両アプリは一つのPortableのPython・ライブラリ・OCRモデルを共有します。PCへのPython導入や開発ソースのcheckoutは不要です。

## 移動先の条件

- Windows x64、書き込み可能なローカルフォルダーと十分な空き容量が必要です。部品・復元ZIP・展開先を同時に保持する場合は約12GB以上を目安にしてください。
- XDWの登録・描画・原文表示・注釈出力には、移動先で利用可能なDocuWorks本体とXDWAPIが必要です。これら、SDK、製品の認証情報は同梱しません。
- GPU OCRには対応するNVIDIA GPUとドライバーが必要です。CPU専用OCRはこの固定環境では保証しません。OCRが使えない場合もWorkbenchの手入力・確認・保存・Excel出力を利用できます。
- DocuWorks 10.1.1のある本PCで合成文書を検証します。9.1・別の物理PC・全DPI設定の動作保証ではありません。

## 新しく使う

1. 同じ版の全部品と結合BAT・manifestを取得し、SHA256を照合します。OCR形式のtransport ZIPはそれぞれを同じフォルダーに展開し、結合ツールも展開して`join_parts.bat`を実行します。
2. 結合したZIPを新しいフォルダーへ展開します。旧Portableや既存案件には上書きしません。フォルダー名に日本語や空白を含められます。
3. `Workbench開始.bat`を実行し、新しい案件を作ります。`projects`と`settings`は初期状態で空です。環境だけを確認する場合は`Workbench開始.bat --diagnostics`を使います。
4. XDWを登録し、読み取りテンプレートを作成・選択します。複数文書への適用はプレビューを確認して実行します。OCR候補を原文と比較し、採用値を訂正・確認した後にExcelへ出力します。
5. 台帳への照合は「出力」画面から開きます。条件とプレビューを確認し、除外理由を保存して、新しいXDWコピーへ枠を付けます。原本を上書きしません。

従来のOCR・Viewer校正フローは`OCR開始.bat`、`校正結果取込.bat`、`全文Excel出力.bat`を使います。元OCRの確認順を調べるには`OCR確認一覧.bat`を使ってください。

## 案件ごと移動する

保存してからアプリとそのワーカーを終了し、バックアップを作成して、Portableフォルダー全体をコピーまたは移動します。`projects`内の案件と`settings`内の共通設定を一緒に保持してください。案件内の原本参照は相対パスです。開いたままのDB・ロック・処理中のフォルダーを移動しません。

台帳照合を移動後に続ける場合は、元台帳を案件内またはPortable内の`INPUT`等へ置いてからプレビューを保存してください。その範囲の元台帳参照も相対パスで保存し、移動先で同じ台帳のSHA256を検証します。Portable外の台帳と、旧版で保存した絶対パスのセッションは元の場所を引き続き参照します。移動後に見つからない場合は、現在の台帳を選び直して再プレビューしてください。

配布候補には実文書・台帳・利用者のDB・個人設定を含めません。利用後のPortableには登録した文書・訂正・台帳コピーが保存されるため、再配布する際は新しい初期状態の配布物を使ってください。
