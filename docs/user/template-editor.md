# 画面でテンプレートを作る

DW-OCR Portable v0.6.0 / Integrations 0.12.0で追加した機能です。旧版Portable v0.5.0には含まれません。
WindowsのTkinter/ttkとPillowを使い、処理はPC内で完結します。

## 最初の作成

1. 見本の校正を終え、「校正結果取込.bat」でReviewed Resultを保存します。
2. 「テンプレート作成.bat」を開き、「新規作成」を押します。
3. 見本の`reviewed.json`が入っているフォルダーを選び、テンプレート名を入力します。
4. 「Viewerで開く」を押します。作業用コピーに取得したい項目ごとの四角形を描き、保存して閉じます。
5. 「保存後に再読込」を押します。左の画像または右の一覧で矩形を選び、項目名を入力します。
6. 帳簿名などを照合する範囲は用途を「適用判定」に切り替え、見本から入力された期待文字を確認します。
7. 「取得結果を確認」で値と確認事項を読み、「この内容で登録」を押します。確認事項があるときはチェックが必要です。

四角形のカスタムプロパティをViewerで入力する必要はありません。通常は項目名だけを入力し、用途「取得」・必須・文字の連結を既定値として使います。結合を空白・改行へ変える場合は「詳細設定」を開きます。出力列の順番は一覧の上下ボタンで変更します。

ページ切替と拡大に対応します。重なった矩形は繰り返しクリックするか一覧で選択できます。矩形の追加・移動・削除はViewerで行います。作業用XDWの本文を直したい場合は、校正用XDWを修正してReviewedを再取り込みし、新規作成してください。

## 保存先と再開

```text
Portable/
  テンプレート作成.bat
  template-drafts/<識別子>/       作業用XDW、下書き、固定した見本
  templates/帳簿A/v001/
    source-template.xdw
    template.json
    manifest.json
    authoring/                   改訂用の見本・設定・検証情報
```

入力内容は短い待ち時間の後に自動保存します。「下書きを保存」またはCtrl+Sでも保存でき、途中で閉じても一覧から再開できます。項目名が未入力でも下書きを保存できます。Viewer内の未保存編集はViewer側で保存してください。

登録済み一覧から「選んだ版を改訂」を使うと、見本と設定を引き継いだ新しい下書きを作ります。登録時はv002、v003と版を追加し、以前の版は上書きしません。`templates`全体を別のPortableへコピーしても、登録時の見本から改訂できます。`authoring`のない従来テンプレートは最初の改訂時に対応するReviewedを選択します。

従来版が`templates/帳簿A/`の直下へ登録されている場合は、その版を保持し、改訂を`templates/帳簿A-versions/v001/`から保存します。

見本には文書の文字、画像、保存済みXDW、元の文書情報が含まれます。テンプレートを共有するときは見本も共有することになります。配布用Portableには利用者のテンプレート・下書きを含めません。

## 登録できない場合

項目名の未入力・同じ用途での重複、範囲外の矩形、期待文字と見本の不一致は設定を修正します。必須項目の候補なし・空文字、未対応文字方向、由来情報の問題、適用判定なしは画面で内容を確認してから登録できます。

矩形を動かしても識別情報が残っていれば項目名を保持します。複製で識別情報が重複した矩形や、新しく描いた矩形は項目名を再設定します。位置だけで以前の名前を割り当てることはありません。

作業用XDWの文字・位置・ページ構造が見本と異なる場合は登録できません。Viewerで保存して閉じた後に再読込してください。回転ページ、付箋・グループ内の矩形は今回の対象外です。SDKの保存パス制限があるため、Portableは短い書込み可能な場所へ置きます。

取得後の適用・Structured Result保存・CSV出力は既存の[テンプレートからCSVまで](template-csv.md)の操作を使います。画面が表示する取得値も同じ判定処理を使います。登録版が異なる結果は、同じテンプレートのCSVとして混ぜません。

開発環境での起動は`python -m docuworks_integrations template-editor --app-root <保存先>`です。PythonにTkinterとPillowが必要です。既存のCLI/API利用時には画面の依存機能を読み込みません。
