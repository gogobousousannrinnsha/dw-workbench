# 矩形テンプレート開発候補の検証（2026-09-19）

対象: Core 1.0.1 / Integrations 0.10.0 開発候補。
登録・抽出・保存/CLIの3段階で実装した。公開版やPortableへの反映は含まない。

## ローカルで確認したこと

| 試験 | 結果 |
| --- | --- |
| Integrations全体とscriptsのDLL不要試験（Python 3.13.15） | 632件成功 |
| CoreのDLL不要試験 | 136件成功。既存のinstalled_bundle比較試験1件はCIと同じ除外 |
| 実SDKのテンプレート試験 | 合成XDWを使った6件成功 |
| 展開したsdistからの訂正・Reviewed・テンプレート試験 | 405件成功、展開元を変更せず実行 |
| Core/Integrationsのwheel・sdist | 4ファイルの作成、内容監査、メタデータ検査が成功 |
| 追加CLIのSDKエラー表示 | 個別の例外型でも終了コード1、日本語表示、完成結果なし |
| 英語Windows相当の出力文字コード | cp1252を指定した子プロセス4件で、日本語のヘルプ・確認・適用・エラー出力を検証 |

実SDKではユーザー定義属性の保存・再読込み、不正型、付箋内の属性、矩形以外の属性を
確認した。合成文書の「AB-」「123」を部品番号「AB-123」へ結合し、温度「80℃」を
取得した。適用判定が一致する場合としない場合を試験した。付箋メモの除外、
入力の不変性、保存結果の再読込み、ページ構造未検証フラグの維持も確認した。

DLL不要試験にはReviewed 1.0/2.0、中心点の境界、行の連鎖防止、結合方法、
前後空白だけの除去、全半角を区別した条件判定、必須/任意、空文字/候補なし、
縦書き/回転、重なる矩形、由来情報の保持、独立読込み、JSONL一致、
再ハッシュ後の不正な値・候補の検出、入力変更、保存失敗時の原子性を含む。

Windowsの一時領域のアクセス制限に対しては、試験用の独立した保存先または
ビルドと同じ実行環境で検査した。OSの権限・セキュリティ設定は変更していない。

## 検証の範囲

実SDKの結果はこの環境のDocuWorks 10.1系・合成XDWについての証拠である。
Viewerの手操作、実帳票、DocuWorks 9.1の実動作、Portableの運用確認は未実施。
Python 3.10～3.13のCI結果は各PR・開発ブランチのチェックを参照する。

初回CIでは全Python版の機能試験が成功した一方、英語Windowsのcp1252で共通ヘルプが
UnicodeEncodeErrorとなった。新コマンドと共通ヘルプのリダイレクト出力をUTF-8へ
固定し、同じ条件で再現する回帰試験を追加した。

仕様と操作例は[矩形テンプレート 1.0](RECTANGLE_TEMPLATE.md)を参照。
